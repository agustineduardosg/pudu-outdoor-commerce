# Sistema de firma de prenda PUDU

Estado: dirección aprobable para prototipo. Las medidas finales deben adaptarse a la prueba real de bordado y a cada tejido.

## Principio

La prenda debe reconocerse como PUDU desde distintos ángulos sin llenarla de logotipos. El sistema usa una marca principal, una marca secundaria específica por categoría y una costura común denominada **Rastro PUDU**.

No se utilizará la bandera chilena, una etiqueta vertical colgante ni la ubicación exacta de la referencia Haka Honu. El recurso propio de PUDU nace de la geometría de montaña del logo y de la paleta bosque–óxido.

## 1. Marca principal

- Símbolo completo más palabra `PUDU`.
- Pecho izquierdo en softshell; bolsillo de pecho en polar.
- Ancho preliminar: 30–35 mm.
- Bordado monocromo de alta densidad o transferencia adecuada al tejido.
- Color hueso sobre fondos oscuros; bosque u obsidiana sobre fondos claros.

## 2. Marca secundaria por categoría

### Softshell Austral

- Símbolo sin palabra en el centro posterior de la capucha.
- Ancho preliminar: 18–22 mm.
- Bordado tonal para que aparezca con la luz, sin competir con el pecho.

### Polar Lenga

- Símbolo sin palabra centrado en la espalda inferior, sobre la basta.
- Ancho preliminar: 24–30 mm.
- Bordado tonal o de contraste bajo.

## 3. Rastro PUDU

- Tres líneas cortas ascendentes inspiradas en el relieve de montaña del símbolo.
- Dos líneas tonales y una línea óxido.
- Tamaño preliminar: 35 × 10 mm.
- Ubicación común: antebrazo exterior izquierdo, cerca del puño.
- Funciona como firma reconocible cuando el pecho o la espalda no aparecen en cámara.

El dibujo debe convertirse en un archivo vectorial y una matriz de bordado propia. No debe improvisarse en cada proveedor.

## 4. Presilla óxido

- Una presilla o bartack de 6–10 mm junto a la basta lateral o base del cierre.
- Uso funcional cuando sea posible, por ejemplo como refuerzo de costura.
- No agregar más de una presilla visible por prenda.

## 5. Cartas de color

### Softshell Austral

1. Obsidiana / Glaciar / Bosque — color héroe.
2. Bosque / Óxido / Obsidiana.
3. Mineral / Hueso / Bosque.
4. Glaciar / Obsidiana / Mineral.

### Polar Lenga

1. Hueso / Bosque — color héroe.
2. Bosque / Obsidiana / Óxido.
3. Óxido / Hueso / Obsidiana.
4. Glaciar / Obsidiana / Bosque.

Para el primer piloto se recomienda fabricar solo dos colores por modelo: el héroe y una variante oscura. Los cuatro colores sirven inicialmente para contenido, preventa y medición de preferencia.

## 6. Validación de fábrica

- bordar el símbolo en tres tamaños sobre retazos reales;
- comprobar legibilidad después de cinco lavados;
- revisar que el polar no se comprima ni deforme alrededor del bordado;
- usar backing suave y recortado para evitar roce;
- validar que la membrana del softshell no pierda funcionalidad en el área bordada;
- preferir transferencia o parche termosellado si perforar el tejido contradice el rendimiento buscado;
- fotografiar cada muestra bajo luz frontal y lateral antes de aprobar producción.
