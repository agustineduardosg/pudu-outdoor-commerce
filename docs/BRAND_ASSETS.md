# Activos de marca

- `public/images/pudu-logo-master.webp`: versión web optimizada derivada del logo entregado por el propietario. Conserva símbolo, wordmark y “Explore and protect”.
- `public/images/pudu-hero-concept.webp`: imagen conceptual original y reemplazable, optimizada para web.
- `public/images/product-*.webp`: 8 packshots conceptuales y reemplazables, separados y optimizados para cargar solo las prendas visibles.

Los másteres PNG de alta resolución se conservan en `assets/source/`; la aplicación sirve únicamente las variantes WebP ligeras.

El archivo original del logo no fue modificado. Antes de producción conviene solicitar una versión vectorial SVG/PDF, variantes monocromas, área de seguridad, tamaños mínimos y confirmación jurídica del nombre y eslogan.

Los activos conceptuales no acreditan materiales, certificaciones, prestaciones ni disponibilidad comercial.
